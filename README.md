# قرطاج — مشروع اللعبة التفاعلية

## النسخة الحالية
- Pilot: `V17.1`
- ملف التشغيل: `index.html`
- اللغة: العربية باللهجة التونسية
- القصة: الفصول الأصلية محفوظة؛ التطوير السينمائي التجريبي موجه إلى مشهد انهيار السور في الفصل الثالث.

## تشغيل النسخة
افتح `index.html` في متصفح حديث. للحصول على أفضل تجربة صوتية، اضغط مرة داخل اللعبة للسماح للمتصفح بتفعيل الصوت. يمكن كتم المؤثرات وتعديل مستواها من زر «صوت سينمائي».

## الاختبارات
يتطلب Node.js 18 أو أحدث:

```bash
npm test
```

الاختبار الحالي يفحص سلامة بنية الملف، عدم تكرار معرّفات HTML، وصحة تحليل JavaScript المضمّن، ووجود عناصر النسخة التجريبية.

## خارطة الطريق
1. تثبيت نسخة Pilot في GitHub مع وسم إصدار واضح.
2. استكمال اختبار التفاعل والصوت على Android فعلياً.
3. تحسين الرسومات الأصلية للشخصيات والخلفيات، مع الحفاظ على النصوص والقرارات.
4. تجهيز غلاف Android باستخدام Capacitor بعد استقرار نسخة الويب.
5. بناء APK عبر GitHub Actions واختباره على الهاتف.

## قواعد الحفاظ على المشروع
- لا تُعدّل القصة أو اللهجة أو أسماء الشخصيات دون طلب صريح.
- لا تستبدل نسخة مستقرة دون إنشاء commit جديد.
- كل تحسين بصري/سمعي يجب أن يكون قابلاً للتعطيل أو احترام `prefers-reduced-motion` عند الإمكان.
