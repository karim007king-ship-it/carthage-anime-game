# QARTON — آخر يوم في قرطاج

## تعريف المشروع
لعبة قصصية تفاعلية باللغة العربية باللهجة التونسية، بهوية QARTON السينمائية.

- ملف القصة الأصلي: `index.html`
- نسخة الويب: تُجهّز إلى `www/index.html` بواسطة `npm run prepare:web`
- تكامل Android: Capacitor
- معرّف الحزمة: `com.qarton.carthage`
- إصدار القصة: `V17.1`
- إصدار تكامل Android: `V17.3`

## بنية الواجهة الرئيسية
تعرض واجهة QARTON الثابتة أربع بطاقات رئيسية:

1. **القصة:** تستدعي أزرار اللعبة الأصلية لبدء قصة جديدة أو فتح الأجزاء المتاحة.
2. **عالم قرطاج:** دليل قراءة للشخصيات والأماكن الموجودة في القصة.
3. **التقدم والحفظ:** متابعة آخر حفظ وتصدير/استيراد النسخ الاحتياطية عبر أدوات الحفظ الأصلية.
4. **الإعدادات:** ربط عناصر الصوت السينمائي الأصلية، دون اختراع إعدادات غير موجودة.

تُزال واجهة QARTON عند بدء اللعب. عند استدعاء إجراء قصصي، تُكشف طبقة اللعبة الأصلية حتى تبقى رسائل التأكيد والأزرار الأصلية قابلة للتفاعل.

## خريطة الملفات
- `index.html`: المصدر الأصلي للقصة والواجهة التفاعلية.
- `scripts/prepare-web.cjs`: تجهيز نسخة Android، وحقن وظائف الحفظ والتشخيص والواجهة.
- `scripts/qarton-main-tree.js`: واجهة QARTON والتنقل بين أقسامها.
- `scripts/qarton-premium-home.js`: توافق تنسيق القائمة القديمة مع بنية React.
- `scripts/qarton-home-inspector.js`: أداة قياس تشخيصية للواجهة الرئيسية فقط.
- `tests/`: اختبارات سلامة HTML والحفظ والواجهة ومسارات التنقل.
- `.github/workflows/android-apk.yml`: فحوصات المشروع وبناء APK.

## التطوير والاختبار
يتطلب المشروع Node.js 22 أو أحدث.

```bash
npm install
npm test
npm run prepare:web
```

تتحقق الاختبارات من:
- سلامة HTML وتحليل JavaScript المضمّن وعدم تكرار معرّفات العناصر.
- استعادة نسخة الحفظ المؤكدة للفصل الخامس وعدم استبدال الحفظ الصحيح الموجود.
- عقود واجهة QARTON وأبعادها وعناصرها.
- ربط الأزرار الأصلية دون نسخها أو نقلها أو تعديل مخطط الحفظ.
- تجهيز ملفات Android والتحقق من تطابق HTML المعبأ مع النسخة المجهزة.

## قواعد الحفاظ على المشروع
- لا تعدّل القصة أو اللهجة أو الشخصيات أو القرارات دون طلب صريح.
- لا تغيّر مفاتيح التخزين أو بنية الحفظ أو بذرة الاستعادة دون اختبارات مستقلة.
- لا تحذف ملفات أو أنظمة قديمة قبل التأكد من عدم اعتماد أجزاء أخرى عليها.
- أوقف مراقبات الواجهة غير اللازمة عند بدء اللعب لتقليل العمل أثناء المشاهد والفصول.
- لا تدمج تغييرات الواجهة في `main` ولا تستبدل APK المثبت قبل نجاح الاختبارات والبناء والتحقق على الهاتف.
- حافظ على معرّف الحزمة `com.qarton.carthage` ومفتاح التوقيع المستقر لتجنب تعارض التثبيت.
