# قرطاج — لعبة QARTON التفاعلية

## حالة المشروع

- إصدار قصة الويب: `V17.1`
- إصدار تكامل Android: `V17.3`
- ملف اللعبة الأصلي: `index.html`
- اللغة: العربية باللهجة التونسية
- هوية الاستوديو: **QARTON — قرطون**
- الشعار: **CULTURE • POWER • CINEMA**

## تشغيل اللعبة

افتح `index.html` في متصفح حديث. لتفعيل الصوت، اضغط مرة داخل اللعبة إذا طلب المتصفح ذلك. يمكن كتم المؤثرات وتعديل مستواها من زر «صوت سينمائي».

## متطلبات التطوير

- Node.js 22 أو أحدث.
- npm.
- Android SDK وJava 21 لبناء APK عبر Android/Capacitor.

## أوامر المشروع

```bash
npm install
npm test
npm run prepare:web
npm run android:sync
```

يُنشئ `prepare:web` نسخة Android الجاهزة في `www/index.html` انطلاقاً من ملف اللعبة الأصلي. لا تعدّل الملف الناتج يدوياً؛ أعد توليده بعد كل تغيير في المصدر أو ملفات النظام.

## تنظيم الملفات

| المسار | المسؤولية |
| --- | --- |
| `index.html` | اللعبة الأصلية: القصة، المشاهد، المحرك، والحفظ الأساسي |
| `styles/qarton-design-system.css` | ألوان QARTON ومكوّناته المشتركة |
| `styles/qarton-carthage-home.css` | تنسيق واجهة اللعب/القائمة الأصلية القديمة عند الحاجة، وقواعد Carthage المرتبطة بها |
| `scripts/qarton-premium-home.js` | محوّل تنسيق واجهة اللعب، مع تعطيل قائمة QARTON القديمة عند تفعيل العزل |
| `scripts/qarton-isolated-home.js` | شاشة QARTON الرئيسية المستقلة، وتفويض الأزرار إلى معالجات React الأصلية |
| `scripts/prepare-web.cjs` | تجهيز نسخة الويب وحقن تكامل Android |
| `scripts/apply-android-branding.cjs` | توليد أيقونات Android وربطها بالـ Manifest |
| `tests/` | اختبارات سلامة اللعبة والحفظ وتكامل Android |
| `docs/` | مواصفات التصميم وبنية المشروع وقواعد التطوير |
| `.github/workflows/android-apk.yml` | الاختبارات وبناء APK ورفع artifact |

للتفاصيل وقواعد إضافة لعبة جديدة إلى منظومة QARTON، راجع `docs/project-structure.md` و`docs/qarton-design-system.md`.

## قواعد الحفاظ على اللعبة

1. لا تغيّر القصة أو اللهجة أو الشخصيات أو تسلسل الاختيارات دون طلب صريح.
2. لا تغيّر مفاتيح التخزين أو صيغة الحفظ دون ترحيل واختبارات توافق.
3. لا تحذف القائمة القديمة أو معالجاتها قبل اختبار كل وظيفة بديلة على Android فعلياً.
4. حافظ على فصل واجهة QARTON عن منطق القصة قدر الإمكان.
5. كل تغيير في تجهيز Android يجب أن يمر عبر `npm test` ثم بناء APK.
6. لا ترفع ملفات البناء المؤقتة أو مفاتيح التوقيع أو بيانات الحفظ الخاصة إلى Git.

## التحقق

يشغّل `npm test` اختبارات:
- بنية اللعبة والسكربتات المضمّنة.
- سلامة استرجاع الحفظ وعدم الكتابة فوق حفظ صالح.
- توليد أيقونات Android وتحديث مراجع `AndroidManifest.xml`.

نجاح الاختبارات والبناء لا يعوّض اختبار اللمس والصوت والتنقل والحفظ على هاتف Android فعلي.

## هوية QARTON المشتركة

QARTON نظام تصميم مشترك لكل ألعاب الاستوديو. تبقى الهوية ثابتة، بينما تحتفظ كل لعبة بعالمها الفني وقصتها وطريقة تفاعلها. لا تنسخ لوحة الألوان والمكوّنات في كل مشروع؛ أعد استخدام النظام المشترك ووسّعه عند الحاجة.
